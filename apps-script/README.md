# PayNote · Apps Script

`Code.gs` คือ API ของแอป PayNote ทำงานกับชีต **PayNote - บันทึกการเงิน**
แอปเขียนแท็บ Transactions, Wallets, Categories, Goals และ Settings ผ่านสคริปต์นี้
แท็บ Summary และ Trends เป็นสูตรอย่างเดียว ห้ามพิมพ์ทับ

## ติดตั้ง (ครั้งเดียว)
1. เปิดชีต → **ส่วนขยาย → Apps Script**
2. ลบโค้ดที่มีอยู่ทั้งหมด วาง `Code.gs` แล้วกดบันทึก
3. เลือกฟังก์ชัน `setupToken` แล้วกด **เรียกใช้** อนุญาตสิทธิ์ แล้วคัดลอก TOKEN จาก Execution log
4. **การทำให้ใช้งานได้ → การทำให้ใช้งานได้รายการใหม่ → เว็บแอป**
   - เรียกใช้ในฐานะ: ฉัน
   - ผู้ที่มีสิทธิ์เข้าถึง: ทุกคน
5. คัดลอก URL ของเว็บแอป (ลงท้ายด้วย `/exec`)
6. ในแอป PayNote: แท็บตั้งค่า → ใส่ URL และ TOKEN → บันทึกและเชื่อมต่อ

ถ้าแก้ `Code.gs` ภายหลัง ให้ใช้ **จัดการการทำให้ใช้งานได้ → แก้ไข → เวอร์ชันใหม่** URL จะเหมือนเดิม

## ข้อมูล
- ยอดของรายจ่ายและการจ่ายจากกระปุก = ยอดรวมที่จ่ายจริง (รวมค่าธรรมเนียมแล้ว) คอลัมน์ค่าธรรมเนียมเก็บไว้ดูเฉยๆ
- ค่าธรรมเนียมตอนย้ายเงินจ่ายเพิ่มจากกระเป๋าต้นทาง และนับเป็นรายจ่ายในหมวดที่ตั้งไว้ (Settings: transfer_fee_category)
- หมวด กระเป๋า หรือกระปุกที่มีรายการแล้ว ถ้าสั่งลบจากแอปจะถูกซ่อน/ปิดแทน ประวัติจึงไม่หาย
- ทุกการเขียนอ้างอิงด้วย id ส่งซ้ำก็ไม่เกิดแถวซ้ำ
