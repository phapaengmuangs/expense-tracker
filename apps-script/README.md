# Apps Script สำหรับชีต "การเงินนาโกย่า - ระบบบันทึก"

ไฟล์ `Code.gs` คือ API ของแอป PayNote ใช้เขียนรายการลงแท็บ `Transactions` สร้างและแก้กระปุกในแท็บ `Funds` และดึงยอดใช้จ่ายรอบนี้/รอบก่อน ยอดบัญชี และกระปุกกลับมา

## ติดตั้งครั้งแรก

1. เปิดชีต → เมนู **ส่วนขยาย (Extensions) → Apps Script**
2. ลบโค้ดเดิมใน `Code.gs` แล้ววางโค้ดจากไฟล์นี้ทั้งหมด กดบันทึก
3. เลือกฟังก์ชัน `setupToken` ในแถบด้านบน แล้วกด **เรียกใช้ (Run)** อนุญาตสิทธิ์ แล้วคัดลอก TOKEN จากบันทึกการดำเนินการ (Execution log)
4. กด **ทำให้ใช้งานได้ (Deploy) → การทำให้ใช้งานได้รายการใหม่ (New deployment)** → ประเภท **เว็บแอป (Web app)**
   - เรียกใช้ในฐานะ (Execute as): **ฉัน (Me)**
   - ผู้ที่มีสิทธิ์เข้าถึง (Who has access): **ทุกคน (Anyone)**
5. คัดลอก URL ที่ลงท้ายด้วย `/exec` แล้วนำ URL และ TOKEN ไปใส่ในแอป แท็บ ⚙️ ตั้งค่า → เชื่อมต่อ Google Sheet

## เมื่อแก้โค้ดภายหลัง

Deploy → **จัดการการทำให้ใช้งานได้ (Manage deployments)** → แก้ไข (ไอคอนดินสอ) → เวอร์ชัน **ใหม่** → Deploy
แบบนี้ URL เดิมจะยังใช้ได้ ถ้าสร้าง deployment ใหม่ จะได้ URL ใหม่ และต้องไปใส่ในแอปอีกครั้ง

## ความปลอดภัย

- TOKEN เก็บอยู่ใน Script Properties และในโทรศัพท์เท่านั้น ไม่อยู่ในโค้ด ไม่อยู่ใน repo และไม่อยู่ในไฟล์สำรองของแอป
- ถ้าสงสัยว่า TOKEN รั่ว ให้เรียกใช้ `setupToken` อีกครั้ง แล้วใส่ TOKEN ใหม่ในแอป TOKEN เก่าจะใช้ไม่ได้ทันที
- สคริปต์เขียนเฉพาะคอลัมน์ A ถึง M ของแท็บ Transactions และคอลัมน์ A ถึง H ของแท็บ Funds และตรวจทุกรายการก่อนเขียน (ประเภท ยอด บัญชี หมวด กระปุก)
